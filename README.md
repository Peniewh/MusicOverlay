# Music Overlay

Прозрачный оверлей-плеер для Dota 2 и других игр. Показывает обложку, название и управление музыкой поверх любой игры. Работает с локальными файлами, YouTube, SoundCloud и VK Music.



## Возможности

- 🎵 Обложка, название, исполнитель, прогресс, время
- ⏯ Управление: плей/пауза, следующий, предыдущий, shuffle, repeat
- 📋 Плейлист со списком треков
- 🔊 Ползунок громкости
- 📥 Загрузка из YouTube, SoundCloud, VK Music
- 🖥 Трей с быстрым доступом
- ⌨️ Глобальные хоткеи (настраиваемые по нажатию клавиш)
- 💬 Всплывашка при смене трека
- 🚀 Автозапуск с Windows
- 🎨 Прозрачный фон, click-through, анимация

## Установка

### Готовый exe (проще всего)

1. Скачай последний [Release](https://github.com/Peniewh/MusicOverlay/releases)
2. Распакуй архив в любую папку
3. Установи [VLC 64-bit](https://www.videolan.org/vlc/) (если ещё нет)
4. Запусти `MusicOverlay.exe`

### Из исходников

```bash
git clone https://github.com/Peniewh/MusicOverlay.git
cd MusicOverlay
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python musicoverlay.py
```

## Использование

### Хоткеи (по умолчанию)

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+M` | Показать / скрыть оверлей |
| `Ctrl+Shift+C` | Click-through (клики уходят в игру) |
| `Ctrl+Shift+Space` | Плей / пауза |
| `Ctrl+Shift+←/→` | Предыдущий / следующий трек |
| `Ctrl+Alt+→` | Следующий трек (без shuffle) |
| `Ctrl+Shift+↑/↓` | Громкость |
| `Ctrl+Shift+Q` | Выход |

Меняются в настройках: **ПКМ по трею → Настройки** → кликни в поле хоткея и просто нажми нужную комбинацию клавиш.

### Как пользоваться

- **ЛКМ по оверлею и тащи** — переместить
- **ПКМ по оверлею** — контекстное меню (добавить файлы, ссылку, VK, плейлист, выход)
- **Иконка в трее** — ЛКМ показать/скрыть, ПКМ меню (Настройки, Плейлист, Выход)
- **Кнопка ☰** на оверлее — открыть плейлист

### В Dota 2

1. Настройки игры → Видео → **«Оконный без рамки»**
2. Запусти оверлей
3. `Ctrl+Shift+C` — включи click-through, чтобы клики уходили в игру

### Если хоткеи не работают в игре

Запусти оверлей **от имени администратора** — `keyboard` на Windows требует прав админа, чтобы видеть клавиши поверх игр.

## Подключение VK Music (опционально)

Оверлей работает **без VK**: локальные файлы, YouTube, SoundCloud.

Для музыки из VK нужен токен — ключ доступа к API. Два способа:

**Способ 1 (через логин/пароль):**

1. ПКМ по трею → **Настройки…**
2. В блоке «VK Music» нажми **«Получить токен через логин/пароль»**
3. Введи логин VK (телефон или email) и пароль
4. Если есть 2FA — код из SMS
5. Токен сохранится автоматически

**Способ 2 (если первый не сработал):**

1. Открой [vkhost.github.io](https://vkhost.github.io/)
2. Выбери приложение **Kate Mobile** или **Boom**
3. Войди в VK, скопируй токен из адресной строки (фрагмент между `access_token=` и `&expires_in`)
4. Вставь токен в **Настройки → VK токен**

**Как пользоваться VK:**

- ПКМ по трею → **«Добавить из VK…»**
- Вставь ссылку вида `https://vk.com/music/playlist/516186282_19_400e411c825b63c178` (с ключом доступа — для приватных плейлистов)
- Все треки скачаются в `downloads\` и добавятся в плейлист

⚠️ **Риски:** при слишком частых запросах VK может временно ограничить аккаунт. Не качай сотни треков подряд и не делай это автоматически.

## Сборка exe

```
build_exe.bat
```

Результат — `dist/MusicOverlay/MusicOverlay.exe`.

Требуется [PyInstaller](https://pyinstaller.org/) (`pip install pyinstaller`) — bat-файл установит его сам.

## Требования

- Windows 10/11 (64-bit)
- Python 3.10+ (для запуска из исходников)
- [VLC Media Player 64-bit](https://www.videolan.org/vlc/) — обязательно

## Известные проблемы

- **`OleInitialize() failed`** — конфликт COM. В коде уже стоит `CoInitializeEx(STA)` в начале, обычно помогает. Если нет — закрой все процессы `python.exe` в диспетчере задач.
- **VK не находит плейлист** — проверь, что ссылка содержит access key (третью часть вида `..._abc123def456`). Публичные плейлисты могут быть недоступны — VK часто требует ключ.
- **Хоткеи не работают в игре** — запусти от админа.
- **Не находит `libvlc.dll`** — установи VLC 64-bit в путь по умолчанию.
